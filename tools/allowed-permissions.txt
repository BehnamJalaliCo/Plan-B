# Every permission the merged RELEASE manifest may request. CI and the release script fail if
# the manifest asks for anything else (tools/check_permissions.sh). Adding a line here is a
# product decision: update PRIVACY.md, docs/SECURITY_REVIEW.md and the store listings too.

# Optional AI assistant (core:ai): sends the text the user chooses to the provider the user
# configured with their own key. Also the one-time handwriting model download of Plan-B Pro
# notes (#18, ML Kit, only after the user agrees). Nothing else in the app uses the network.
android.permission.INTERNET

# Reminders (core:notifications).
android.permission.POST_NOTIFICATIONS
android.permission.RECEIVE_BOOT_COMPLETED
android.permission.SCHEDULE_EXACT_ALARM

# Plan-B Pro purchases through the installed Cafe Bazaar app (Poolakey).
com.farsitel.bazaar.permission.PAY_THROUGH_BAZAAR

# Plan-B Pro App lock and locked notes (androidx.biometric): the device's own fingerprint, face
# or screen lock confirms the user. USE_FINGERPRINT is the same for Android 8.x (API 26–27).
android.permission.USE_BIOMETRIC
android.permission.USE_FINGERPRINT

# Plan-B Pro two-way sync with device calendars (core:calendarsync): runtime permissions asked
# only when the user turns on "Sync with device calendars" in Settings. Reads the calendars the
# user chooses to show; writes and deletes only events Plan-B created (CUSTOM_APP_PACKAGE marker).
android.permission.READ_CALENDAR
android.permission.WRITE_CALENDAR

# WorkManager (automatic backups, 30-day trash purge, Pro home-screen widgets via Glance): keeps the device awake while a short
# background job runs. Its foreground-service permission is removed in the manifest.
android.permission.WAKE_LOCK

# Plan-B Pro voice notes (#19) and voice input (#40): runtime permission asked in context, with an
# explanation, only when the user records a voice note or taps a microphone to dictate (or
# dictates a transcript on Android 12 and older). Recordings stay in the note on the device;
# dictation keeps no audio (the device's speech service returns only text).
android.permission.RECORD_AUDIO

# Normal (install-time, no prompt). Plan-B Pro handwriting to text (#18): ML Kit downloads the
# handwriting model only after the user agrees, through WorkManager, waiting for a network (or
# for Wi-Fi when "Only over Wi-Fi" is on). Nothing else reads the network state.
android.permission.ACCESS_NETWORK_STATE

# Added by AndroidX core: protects the app's own non-exported dynamic receivers.
com.behnamjalali.planb.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION
